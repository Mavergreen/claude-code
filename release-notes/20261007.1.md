First release. It succeeds the Mavericks Forever installer and patches Claude Code the same way, using drydock-macho-rewrite instead of Wowfunhappy's `patch_macho`, `add_version_min` and `change_dylib`.

Checked on Claude Code 2.1.292: both toolchains patched the same pristine binary from Anthropic. Every byte of code and data is identical (241,362,112 bytes compared). The load commands and the linker tables differ only as follows:

- **Library paths.** The three system libraries point at `/usr/local/mavergreen/recaulk/lib/libRecaulkSystem.dylib`, `/usr/local/mavergreen/libcxx22/lib/libc++.1.dylib` and `/usr/local/mavergreen/icu/lib/libicucore.dylib`, rather than Mavericks Forever's `@loader_path/../S.dylib`, `I.dylib` and `c++.1.dylib` aliases. The longer paths leave 24 bytes of header pad instead of 96.
- **Linker tables.** The rebase, bind, export, symbol, string, indirect-symbol, function-start and data-in-code tables have byte-identical contents. drydock packs them in the order `codesign_allocate` expects and drops 1,927,816 bytes the binary no longer references, so the patched copy is 1.9 MB smaller and can be re-signed on 10.9. Mavericks Forever's cannot ("dyld_info out of place").
- **SDK version.** The minimum OS is 10.9 in both. Mavericks Forever also sets the SDK field to 10.9. drydock keeps Anthropic's (26.5).
